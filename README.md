## Commands for bash
- ls | lists all files
- cd (filename) | goes to foleder
- cd .. | goes back one folder
- zed (filename) | opens file in zed
- mkdir (foldername) | makes a new folder
- touch (filename) | makes a new file
- rm (filename) | removes a file
- rm -r (folder name) | removes a folder
- dotnet new console | makes the tings needed to run a c# program (unsure how it works)
- dotnet build | makes the code into machine code so the program works (unsure)
- dotnet run | runs the c# program from the build that was made

## git commands
- git log --all --oneline --graph | gives a nice overview of the timeline
- git add (folder) | adds folder to the git
- git commit -a -m "(comment)" | adds all to working tree with comment
- git push | uploads the new version to github
- git merge | will merge your code *(think of it mostly as going to the newest version after fetch)*
- git fetch | cheks if own version is up to date, if not will get newest version and need to merge.
